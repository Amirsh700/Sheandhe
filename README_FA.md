# She&He Android — نسخهٔ اولیهٔ قابل توسعه

این پروژه یک پوستهٔ اندرویدی با Jetpack Compose برای برند She&He است. طراحی شامل صفحهٔ خانه، استوری‌ها، کارت‌های پست، کشف محتوا، پیام‌ها، پروفایل و بخش نمایشی خدمات مالی است.

## وضعیت فعلی
- لوگوی SH سه‌بعدی به‌عنوان دارایی برند و آیکون لانچر در پروژه قرار گرفته است.
- رابط فارسی و راست‌چین و تم تیرهٔ نئونی دارد.
- تعاملات نمایشی مانند انتخاب تب‌ها و پسندیدن پست‌ها کار می‌کند.
- این نسخه هنوز شبکهٔ اجتماعی آنلاین نیست: ورود/ثبت‌نام، سرور، ذخیرهٔ پست‌ها، آپلود رسانه و پیام‌رسانی آنلاین نیازمند بک‌اند هستند.
- کیف پول فعلاً نمایشی است؛ هیچ پولی جابه‌جا نمی‌کند. کارت‌به‌کارت و قبض/شارژ واقعی نیازمند ارائه‌دهندهٔ مجاز، قرارداد و مجوزهای مربوط است.

## ساخت APK از طریق GitHub Actions با گوشی
۱. یک مخزن جدید در GitHub بساز.
۲. محتویات این پوشه را در مخزن بارگذاری کن (می‌توانی فایل ZIP را در گوشی استخراج کنی و از وب‌سایت GitHub فایل‌ها را اضافه کنی).
۳. به بخش **Actions** برو و workflow با نام **Build SheAndHe APK** را اجرا کن؛ یا یک commit روی شاخهٔ `main` ثبت کن.
۴. پس از پایان موفق، در صفحهٔ اجرای workflow بخش **Artifacts**، فایل `SheAndHe-debug-apk` را دانلود کن.
۵. ZIP آرتیفکت را استخراج و `app-debug.apk` را روی گوشی نصب کن. ممکن است Android برای نصب از منبع مورد اعتماد اجازه بخواهد.

## ساخت روی رایانه با Android SDK نصب‌شده
با JDK 17 و Android SDK Platform 35:
```bash
gradle assembleDebug
```
خروجی: `app/build/outputs/apk/debug/app-debug.apk`

## گام‌های لازم برای نسخهٔ واقعی
- احراز هویت امن و API بک‌اند
- پایگاه داده و فضای ذخیره‌سازی رسانه
- سرویس اعلان‌ها و پیام‌رسانی بلادرنگ
- گزارش محتوا، مسدودسازی، کنترل حریم خصوصی و ابزارهای ضدسوءاستفاده
- اتصال مالی فقط به APIهای مجاز و تأییدشده؛ هرگز اطلاعات کارت یا رمز بانکی را مستقیم در این اپ ذخیره نکنید.
